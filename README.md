## Writing a blog post

Posts are Markdown files that GitHub Pages turns into pages at `/blog/<year>/<slug>/`.

1. Copy `_drafts/how-to-write-a-post.md` into `_posts/` and rename it `YYYY-MM-DD-your-slug.md`.
2. Fill in the front matter (`title`, `description`, `tags`, and `math: true` if the post has equations).
3. Put images in `assets/img/blog/` and link them as `/assets/img/blog/name.png`.
4. Commit and push. The post shows up on `/blog/`, on the homepage (three newest) and in the RSS feed at `/feed.xml`.

Files in `_drafts/` are never published.
